## Project overview

N8N SalesFlow AI is a policy-bound WhatsApp sales-assistance baseline. The repository implements and verifies the full synthetic-local workflow set while keeping all credentialed production integrations explicitly blocked.

## Quick reference

- **Runtime:** n8n 2.30.4 and PostgreSQL 17.10, digest-pinned in Docker Compose.
- **Entry points:** n8n webhook paths under `salesflow/*` plus the UTC Schedule Trigger.
- **State authority:** `database/001-initial.sql`.
- **Workflow authority:** `workflows/01-whatsapp-ingress.json` through `07-error-and-operations.json`.
- **Configuration:** ten versioned JSON contracts in `config/`.
- **Canonical verification:** `powershell -ExecutionPolicy Bypass -File .\tests\run.ps1`.
- **Production status:** blocked; `livePromotionAllowed` is `false`.

## Getting started

1. Install Docker Desktop with Compose and Windows PowerShell 5.1 or PowerShell 7.
2. Run `powershell -ExecutionPolicy Bypass -File .\tests\run.ps1` from the repository root.
3. Read [architecture.md](./architecture.md) before changing state transitions or workflow routing.
