# M08 Hints

## Hint 1 — Diagnostic question

Which current facts can suppress work that was valid when it was originally scheduled?

## Hint 2 — Concept

An appointment stored on a universal timeline is only a candidate. Local allowed hours, the validity of the approved message, a later stop request, and current human control still decide whether it may proceed.

## Hint 3 — Location

Inspect the learner branch's due-work selector, account time rules, approved-message evidence, conversation ownership, and human-transfer intent boundary.

## Hint 4 — Structure

Select work by universal due time, evaluate account-local timing, recheck current suppression rules, persist eligible automated or transfer intent, and let a later scan recover still-due work.

## Hint 5 — Pseudocode

Use this incomplete scheduling outline:

```text
select due work at [UTC ____]
allow only inside [local ____]
require approved message [____]
suppress when opted out or [____]
persist eligible intent [____]
```
